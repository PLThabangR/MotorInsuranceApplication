# Motor Insurance Application

A production-style Motor Insurance application built with .NET 8, following Clean Architecture.

## Purpose

This project is a portfolio-grade demonstration of modern .NET development practices:
Clean Architecture, CQRS with MediatR, EF Core with PostgreSQL, Redis caching,
JWT authentication with ASP.NET Core Identity, Dockerized infrastructure,
and a React + TypeScript frontend (added later).
